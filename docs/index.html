CJD Autopost

CJD Autopost is a private scheduling tool used by Creative Java Developers to publish its own educational Java content to its own YouTube channel, Instagram account and LinkedIn company page at planned times.

It is not offered to the public. It only ever accesses accounts owned by Creative Java Developers, using each platform's official API and permission screen.

CJD Autopost uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
