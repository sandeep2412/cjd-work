Privacy Policy

Last updated: 31 October 2026

CJD Autopost ("the app") is a private tool run by Creative Java Developers to schedule and publish its own content. This policy explains what the app accesses and why.

Who uses the app

Only Creative Java Developers. The app is not offered to other people, and it only connects to accounts that Creative Java Developers owns.

What the app accesses

  • YouTube (Google): permission to upload videos, set thumbnails and add videos to playlists on our own channel.
  • Instagram (Meta): permission to publish reels and images to our own professional account.
  • LinkedIn: permission to publish posts to our own company page.

The app does not read, collect or store personal data about viewers, followers or any other users.

How access tokens are stored

The login tokens granted through each platform's official permission screen are stored only as encrypted GitHub Actions secrets. They are never published, sold or shared with anyone.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to upload our own content to our own channel, and is not transferred to anyone else.

Removing access

Access can be withdrawn at any time from each platform's security settings, for example Google Account → Third-party connections.

Contact

Questions about this policy can be raised at github.com/sandeep2412/cjd-work/issues.
